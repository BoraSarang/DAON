### 0.1 핵심 변화
- **달력이 주인공**: 달력 70% / 오른쪽 시계·날씨 30%. v0.1의 34/40/26 3분할을 폐기한다.
- **대상 사용자**: 70대 어르신. 본문 27~30px, 핵심 숫자 47px 이상, W300 금지, 터치 ≥64px.
- **3화면 로테이션**: 달력(30초) → 날씨(20초) → 시계(20초). 화면별 시간 설정, 터치 동작 설정(대시보드 복귀 기본 / 그 화면에서 멈추기), 패널 열림 중 정지.
- **농사 달력**: 양력 + 음력 + 한국 공휴일 + 24절기 + 절기별 농사일.
- **날씨 메인**: 시간별·7일·강수량·농사 참고 + 비/눈/천둥/맑음 효과.
- **시계 메인**: 둥근 아날로그(기본) / 큰 디지털 / 혼합 선택.

### 0.4 달력 표시 규칙
- 양력 숫자: 기본 `#F5F7FA`, 일요일 `#F07A6A`, 토요일 `#82B4FF`, 공휴일 `#F07A6A`.
- 음력: `음 9/21` (25px, `#A7B0BD`). 상세 패널에서는 `음력 9월 21일`.
- 공휴일: 빨강 + 이름(예: `개천절`, `대체공휴일`, `한글날`). 색만으로 구분하지 않는다.
- 24절기: 초록(`#9ADB8A`) + 이름(예: `한로`, `상강`). 셀 클릭 → 상세 패널.
- 오늘: amber(`#F0B45E`) 배경 + `오늘` 라벨 + 어두운 글씨.
- 인접 월: 32% 불투명. 오늘·공휴일·절기는 인접 월에서도 표시하되 흐리게.
- 월 이동: ‹ › 64px, `오늘` 버튼 56px. 6주 고정으로 월마다 높이 흔들림 없음.

### 0.5 화면 전환
- 화면: `CALENDAR`(홈) / `WEATHER` / `CLOCK`. 250ms 크로스페이드.
- 기본 간격: 달력 30초 → 날씨 20초 → 시계 20초 → 달력. 화면마다 10/20/30/60초로 변경 가능.
- 터치 동작(설정):
  - `대시보드로 복귀`(기본): 날씨·시계 화면을 누르면 즉시 달력 + 타이머 리셋.
  - `그 화면에서 멈추기`: 누른 화면에 그대로 정지, 다시 누르면 자동 전환 재개.
- 설정/상세 패널이 열려 있으면 전환 정지.
- 화면 점 3개는 표시 전용(터치 대상 아님). 하단 안내 문구는 선택한 터치 동작에 맞춰 바뀐다.
- 설정에서 자동 전환 끄기, 화면별 시간, 터치 동작 변경.

### 0.6 70대 접근성 체크 (목업 반영, 구현 시 검증)
- [ ] 본문 ≥27px, 보조 ≥21px, 18px 이하 없음

- [ ] 다이얼로그 대신 인앱 우측 패널 (시스템 바 재등장 방지)
- [ ] 날씨 움직임 끄기, 화면 전환 250ms

## 1. 원칙
- **원거리 가독성**: 1~3m 거리에서 읽힌다. 본문 최소 18sp, 핵심 수치는 72sp 이상.
- **무소음(quiet)**: 장식 최소. 그림자·그라데이션 없음. 위계는 크기·굵기·1dp 선으로 만든다.
- **정보 3분할**: 왼쪽 = 시간, 가운데 = 달력, 오른쪽 = 날씨. 시선이 한 번에 흐른다.
- **색은 의미만**: 강조색 1개(amber)와 상태색(ok/warn/danger)만. 배경은 거의 검정.
- 시스템 UI(권한·다이얼로그·설정 패널)는 Material 3 기본 규칙 유지.
- 최소 접근성: 본문 대비 AA 이상, 터치 타깃 48dp 이상, 텍스트 크기 조절 대응(고정 dp 대신 sp).
