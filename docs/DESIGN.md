### 0.1 핵심 변화
- **달력이 주인공**: 달력 70% / 오른쪽 시계·날씨 30%. v0.1의 34/40/26 3분할을 폐기한다.
- **대상 사용자**: 70대 어르신. 본문 27~30px, 핵심 숫자 47px 이상, W300 금지, 터치 ≥64px.
- **3화면 로테이션**: 달력(30초) → 날씨(20초) → 시계(20초). 화면별 시간 설정, 터치 동작 설정(대시보드 복귀 기본 / 그 화면에서 멈추기), 패널 열림 중 정지.
- **농사 달력**: 양력 + 음력 + 한국 공휴일 + 24절기 + 절기별 농사일.
- **날짜 상세**: 날짜를 누르면 오른쪽 520dp 패널에 절기 설명·농사일·공휴일·이달의 절기를 보여준다(다이얼로그 금지).
- **날씨 메인**: 시간별·7일·강수량·농사 참고 + 비/눈/천둥 효과(맑음·흐림은 정적).
- **시계 메인**: 둥근 아날로그(기본) / 큰 디지털 / 혼합 선택.

### 0.4 달력 표시 규칙
- 양력 숫자: 기본 `#F5F7FA`, 일요일 `#F07A6A`, 토요일 `#82B4FF`, 공휴일 `#F07A6A`.
- 음력: `음 9/21` (25px, `#A7B0BD`). 상세 패널에서는 `음력 9월 21일`.
- 공휴일: 빨강 + 이름(예: `개천절`, `대체공휴일`, `한글날`). 색만으로 구분하지 않는다.
- 24절기: 초록(`#9ADB8A`) + 이름(예: `한로`, `상강`). 셀 클릭 → 상세 패널.
- 오늘: amber(`#F0B45E`) 배경 + `오늘` 라벨 + 어두운 글씨.
- 인접 월: 32% 불투명. 오늘·공휴일·절기는 인접 월에서도 표시하되 흐리게.
- 월 이동: ‹ › 64px, `오늘` 버튼 56px. 6주 고정으로 월마다 높이 흔들림 없음.

### 0.5 화면 전환
- 화면: `CALENDAR`(홈) / `RADIO` / `TV` / `WEATHER` / `CLOCK`. 250ms 크로스페이드.
- 기본 간격: 달력 30초 → 날씨 20초 → 시계 20초 → 달력. 화면마다 10/20/30/60초로 변경 가능.
- 터치 동작(설정):
  - `대시보드로 복귀`(기본): 날씨·시계 화면을 누르면 즉시 달력 + 타이머 리셋.
  - `그 화면에서 멈추기`: 누른 화면에 그대로 정지, 다시 누르면 자동 전환 재개.
- **카드 터치**: 달력 홈의 시계 카드를 누르면 시계 화면, 날씨 카드를 누르면 날씨 화면으로 이동한다(타이머 리셋).
- **`달력` 버튼**: 날씨·시계 화면 상단 바(설정 왼쪽, `accentSoft` 배경)에 둔다. 누르면 달력으로 돌아가 자동 전환이 다시 시작된다. `그 화면에서 멈추기` 모드에서도 대시보드로 돌아갈 길이 항상 보이게 하기 위한 장치다.
- **`라디오`·`TV` 버튼**: 달력 홈 상단 바에서 화면 점 오른쪽, `설정` 왼쪽에 둔다. 설정에서 라디오·TV 화면을 자동 전환에서 빼 두어도 언제든 들어갈 수 있게 하기 위한 길이다(항상 보인다). 라디오가 재생 중이면 `라디오` 버튼이 accent 로 강조되고, TV 재생 중에는 두 버튼 모두 강조하지 않는다(TV 는 화면을 떠나면 멈추기 때문).
- 화면 점은 표시 전용(터치 대상 아님). 하단 안내 문구는 선택한 터치 동작에 맞춰 바뀐다.
- 설정/상세 패널이 열려 있으면 전환 정지.
- 설정에서 자동 전환 끄기, 화면별 시간, 터치 동작 변경.

### 0.5.3 화면 갱신·메모리 규칙
- 시계 값은 ViewModel 의 `StateFlow` 가 아니라 화면에서 `rememberNow(perSecond)` 로 만든다. 초를 보여 주는 화면(시계)만 1초마다, 달력·날씨는 분 경계에서만 갱신한다. 값은 `State` 로 읽는 컴포저블만 다시 그린다.
- `오늘` 날짜는 `derivedStateOf` 로 감싸 날짜가 바뀔 때만 하위(달력 42칸)를 다시 그린다.
- 달력 자산·날씨·위치·기기 캘린더·저장된 일정 읽기는 첫 프레임 뒤(`withFrameNanos`)로 미룬다. 반복 일정 펼침은 `Dispatchers.Default`, 파일·prefs 읽기는 `Dispatchers.IO`.
- 날짜·시간 포매터는 `Formatters.of(pattern, locale)` 로 한 번만 만들어 재사용한다(`DateTimeFormatter.ofPattern` 은 매번 패턴을 해석한다).
- 라디오와 TV 를 오갈 때 쓰지 않는 플레이어는 `release()` 해 코덱·버퍼 메모리를 돌려준다(다시 재생할 때 새로 만든다).

### 0.5.1 날씨 효과
- 비·눈·천둥만 움직인다. 맑음·흐림은 상시 켜짐 기기에서 불필요한 재그리기를 피하려고 정적으로 둔다.
- 설정 `날씨 움직임`을 끄면 효과를 전혀 그리지 않는다.
- 효과는 Compose 애니메이션 대신 프레임 시계로 그린다. 기기의 `애니메이션 끄기`(animator_duration_scale=0)와 무관하게 움직이고, 화면이 바뀌면 루프도 멈춘다.
- 천둥은 6.5초 주기로 두 번 번쩍인다(최대 alpha 0.18). 비는 64줄기, 눈은 64송이.
- 낮/밤에 따라 맑음·구름조금 아이콘이 해/달로 바뀐다. 밤 맑음은 달과 별 3개.

### 0.5.2 날씨 지점 (위치)
- 원칙: **지금 있는 자리**를 먼저 쓴다. 도시 목록은 마지막 수단이다.
- 순서: 기기 위치(프레임워크 `LocationManager`, 네트워크) → 설정에서 저장한 동네 → 도시 칩.
- 권한은 첫 실행 때 한 번만 묻는다(거친 위치). 거부해도 앱은 그대로 동작하고, 설정의 `권한 허용`으로 다시 요청할 수 있다.
- 위치를 못 찾으면 설정 화면에 이유와 지금 쓰는 지점을 한 줄로 알려 준다(무음 실패 금지).
  - 예: `위치를 못 찾아 저장한 동네로 표시합니다: 충주시`
- 저장한 동네는 Nominatim 검색으로 좌표를 받아 `이름 + 가까운 시·군`으로 남긴다(예: `살미면, 충주시`).
- 지점 이름은 달력·날씨·시계 세 화면 모두 같은 문자열을 쓴다(`Place.label()`).
- 도시 칩을 고르면 저장한 동네는 지워진다(의도된 동작 — 도시가 우선).
- Fire HD 10(2019)은 GPS 가 없고 HERE 네트워크 위치도 좌표를 주지 않는다 → 이 기기에서는 저장한 동네가 사실상 기본값.

### 0.8 일정 (T-003/T-004)
- **달력 셀**: 일정이 있는 날은 날짜 숫자 오른쪽에 7dp 점. 오늘 셀은 진한 잉크색, 그 외 amber.
- **오늘 일정 알약 (T-025)**: 달력 그리드를 줄이던 52dp 스트립을 없애고, 상단 바 오른쪽에 1줄 알약(`오늘 일정 09:30 모판 준비 1개 더`)으로 붙인다. 일정이 없으면 그리지 않고, 누르면 오늘 날짜 상세가 열린다. 달력은 6주 그리드가 온전히 보인다.
- **날짜 상세 패널**: 헤더 바로 아래 `일정` 구역. 일정 행(배경 `surfaceAlt`, 10dp 라운드)에 시간·제목·출처·반복. 로컬 일정만 오른쪽 `×` 삭제. 아래 한 줄 입력 + `추가`(높이 46dp 이상, IME Done으로도 저장).
- **날짜 기준 칩**: 입력 위에 `양력 M월 D일` / `음력 M월 D일`(음력 데이터가 있을 때만) 칩. 음력을 고르면 `매년 음력 M월 D일로 반복합니다` 안내가 뜨고 반복 칩은 숨긴다(음력은 항상 매년).
- **반복 칩**: 양력일 때 `없음 · 매주 · 매월 · 매년`. 터치 영역 40dp 이상, 선택 시 `accentSoft` 배경 + accent 테두리.
- **출처 구분**: 로컬 `이 태블릿에서 추가`, 기기 `기기 캘린더 · <캘린더 이름>`(읽기 전용, 삭제 버튼 없음). 반복 일정은 `매년 음력 10월 6일` 처럼 덧붙인다.
- **빈 상태**: `이 날은 일정이 없습니다.` 기기 캘린더가 없으면 `이 기기에는 캘린더 앱이 없습니다. 여기에서 직접 일정을 추가할 수 있습니다.`
- **저장**: SharedPreferences `events` + JSON(반복·음력 필드는 없으면 기본값). 기기 캘린더는 오늘 ±12개월만 읽고, 범위 밖 달은 점 표시가 없을 뿐 달력은 정상.
- **반복 펼침**: 원본 1건만 저장하고 `EventOccurrences` 가 오늘 −24개월 ~ +120개월을 펼친다. 회차 사본은 시리즈 `id` 를 유지한다.
- **회차 건너뛰기 (T-026)**: 로컬 반복 일정 행의 `이 회차만` 을 누르면 같은 줄에 `건너뛰기`/`취소` 확인이 뜬다(다이얼로그 없음). 건너뛴 날짜는 `CalendarEvent.skipDates` 에 `YYYY-MM-DD` 로 저장되고 펼칠 때 빠진다. 시리즈와 다른 회차는 그대로 남는다.
- **권한**: `READ_CALENDAR`는 provider 가 있는 기기에서 첫 1회만 요청. 권한이 있으면 provider 응답 여부로 사용 가능을 판정한다(일정 0건이어도 사용 가능).

### 0.9 키오스크 (T-008)
- 설정 → `키오스크`: `이 앱에 고정` 토글, `부팅 시 자동 시작` 토글.
- 고정 상태는 `ActivityManager.lockTaskModeState`로 읽는다. Device Owner 면 확인 없이, 아니면 Android 화면 고정 확인 창 1회.
- 토글에는 **실제 고정 상태만 저장**한다. 시스템 확인 창을 취소하거나 `ON_RESUME` 에서 풀린 상태면 `고정됨`으로 표시하지 않고 `kioskLock` 도 false 로 맞춘다(다음 시작에 잘못 다시 묻지 않게).
- 부팅 자동 시작은 `BOOT_COMPLETED` 수신 후 설정이 켜져 있을 때만 `MainActivity`를 연다. Fire OS 가 막으면 조용히 실패하고 로그만 남긴다.
- 안내 문구: `고정을 풀려면 뒤로가기와 최근 앱 버튼을 함께 길게 누르세요.`

- 레이아웃(1920×1200): 상단 바 59dp + 지금 방송 패널 235dp + 채널 5×2 타일 + 안내 한 줄.
  - 지금 방송: `지금 방송`/`마지막 채널` 라벨 + `LIVE` 배지, 채널명 64sp, `FM 97.3`, 상태(`재생 중 · 00:12:34`), 큰 재생/멈춤 131dp, 볼륨 −/+(10칸 막대)
  - 채널 타일: 이름 23sp + `FM 주파수`, 선택 시 amber 테두리·이퀄라이저·`재생 중`
- 터치: 화면 빈 곳은 무시(화면 전환 없음). 달력 복귀는 상단 `달력` 버튼 하나.
- 달력 상단 `♪ 채널` 표시는 재생 중에만 나오고 누르면 라디오 화면으로 간다.
- 오류: 채널명 아래 `방송을 불러오지 못했습니다` + `다시 시도` 칩. danger 색은 문구에만 쓴다.
- 색·글꼴은 기존 토큰 그대로. 라디오 전용 크기만 `Home.radio*` 로 추가했다.

### 0.11 TV (v0.4, T-037~T-041)
- 5번째 화면: 달력 → 라디오 → **TV** → 날씨 → 시계. 화면 점 5개(라디오·TV를 빼면 그만큼 줄어든다).
- 레이아웃(1920×1200): 왼쪽 66% = 16:9 영상 판 + 조작 줄, 오른쪽 34% = `채널` 2×3 타일.
  - 영상 판: 검은 배경, 16:9를 넘으면 위아래를 검게 남긴다. 재생 전에는 채널 이름 + `채널을 누르거나 재생 버튼을 누르면 바로 시작합니다`.
  - 조작 줄(150dp): `지금 방송`/`마지막 채널` + `LIVE`, 채널 이름 30sp, `보는 중 · 00:00:12`, 원형 재생/멈춤 84dp, `전체 화면`(재생 중에만 켜짐)
  - 채널 타일: 이름 23sp + 분류(`지상파`/`뉴스`), 보는 중이면 amber 테두리·이퀄라이저·`보는 중`
- **채널 소스**: KBS 1TV·2TV, MBC, SBS 는 ExoPlayer(HLS). **YTN 뉴스·MBC 뉴스는 유튜브 라이브**라 매니페스트가 없어 유튜브 공식 임베드 플레이어를 WebView(`assets/yt_player.html`)로 띄운다. 지상파와 똑같은 영상 판·조작 줄을 쓰고, 전체 화면에서도 같은 WebView 를 옮겨 붙여 끊기지 않게 한다. 재생을 멈추거나 화면을 떠나면 WebView 를 반납한다(비용: 재생 중 PSS 약 250MB).
- **전체 화면**: 영상만 화면에 꽉 채우고 오른쪽 위에 채널 이름 + `전체 화면 나가기`. 뒤로가기는 전체 화면부터 나간다.
- **자동 전환 정지**: `설정 열림 || 날짜 상세 || TV 재생·연결 중 || 전체 화면` 이면 넘어가지 않는다. 재생을 멈추면 남은 시간 뒤 다음 화면으로 간다.
- 터치: 빈 곳은 무시. TV 화면을 떠나면(달력 버튼·뒤로가기·ON_STOP) 재생을 멈춘다. 라디오와 동시에 나오지 않는다.
- 오류: 조작 줄에 `채널을 불러오지 못했습니다` + `다시 시도` 칩. danger 색은 문구에만 쓴다.
- 색·글꼴은 기존 토큰 그대로. TV 전용 크기만 `Home.tv*` 로 추가했다.

## 1. 원칙
- **원거리 가독성**: 1~3m 거리에서 읽힌다. 본문 최소 18sp, 핵심 수치는 72sp 이상.
- **무소음(quiet)**: 장식 최소. 그림자·그라데이션 없음. 위계는 크기·굵기·1dp 선으로 만든다.
- **정보 3분할**: 왼쪽 = 시간, 가운데 = 달력, 오른쪽 = 날씨. 시선이 한 번에 흐른다.
- **색은 의미만**: 강조색 1개(amber)와 상태색(ok/warn/danger)만. 배경은 거의 검정.
- 시스템 UI(권한·다이얼로그·설정 패널)는 Material 3 기본 규칙 유지.
- 최소 접근성: 본문 대비 AA 이상, 터치 타깃 48dp 이상, 텍스트 크기 조절 대응(고정 dp 대신 sp).
