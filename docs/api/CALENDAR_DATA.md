| 파일 | 범위 | 크기 | 내용 |
|---|---|---|---|
| `lunar_2025_2040.json` | 2025-01-01 ~ 2040-12-31 | 154KB | 양력 날짜별 음력 연·월·일·윤달 여부 (5,844일) |

합계 약 230KB. 시작 시 1회 로드 예산(<300KB) 안에 들어온다.

## 2. 형식

### 음력
```json
{
  "version": 1,
  "range": { "from": "2025-01-01", "to": "2040-12-31" },
  "days": {
    "2026-10-31": [2026, 9, 21, 0]
  }
}
```
값은 `[음력 연, 월, 일, 윤달(1/0)]`이다. 날짜 키는 양력 `YYYY-MM-DD`.

### 24절기
```json
{
  "days": {
    "2026-10-23": [
      {
        "index": 19,
        "name": "상강",
        "nameEn": "Sanggang",
        "hanja": "霜降",
        "time": "18:37",
        "longitude": 210,
        "verified": "KASI"
      }
    ]
  }
}
```
- `index` 0~23은 소한부터 동지까지의 달력 순서이며 `term_details_*`의 키와 같다.
- `time`은 KST(UTC+9) 분 단위.
- `verified`는 `KASI`(2026년 공식 값) 또는 `computed`(태양 황경 계산).

### 공휴일
```json
{
  "days": {
    "2026-10-05": [
      {
        "name": "대체공휴일",
        "nameEn": "Substitute Holiday",
        "type": "substitute",
        "substituteFor": "개천절",
        "description": "개천절이 토요일과 겹쳐 지정된 대체공휴일입니다.",
        "descriptionEn": "A substitute holiday because National Foundation Day fell on a Saturday."
      }
    ]
  }
}
```
`type`: `national`(국경일) / `holiday`(공휴일) / `seasonal`(명절) / `substitute`(대체) / `election`(선거).

### 절기 설명
```json
{
  "locale": "ko",
  "terms": {
    "19": {
      "name": "상강",
      "hanja": "霜降",
      "season": "가을",
      "summary": "서리가 내리기 시작하는 때",
      "description": "…",
      "tasks": ["…", "…", "…"]
    }
  }
}
```

## 3. 출처와 기준

### 음력
- 한국천문연구원(KASI) 음양력 데이터를 사용하는 `korean-lunar-calendar` 패키지로 생성.
- 검증: 2025-01-29 = 음 1/1(설날), 2025-10-06 = 음 8/15(추석), 2026-02-17 = 음 1/1, 2026-09-25 = 음 8/15, 2026-10-31 = 음 9/21, 2027-02-07 = 음 1/1, 2027-09-15 = 음 8/15.
- 2025년 윤6월, 2028년 윤5월 등 윤달도 데이터에 포함된다.

### 24절기
- 2026년 24절기는 **우주항공청 2026년 월력요항** 값과 분 단위까지 일치한다.
  - 한로 2026-10-08 15:29, 상강 2026-10-23 18:37, 입동 2026-11-07 18:52, 동지 2026-12-22 05:50.
- 그 외 연도는 태양의 겉보기 황경이 15°의 배수가 되는 순간을 PyEphem으로 계산해 KST로 변환했다.
  - 계산값은 2026년 공식 값과 2분 이내로 대조했다. 1분 단위 반올림 때문에 공식 표와 ±1분 차이가 날 수 있다.
- 절입 시각은 화면에 분 단위로만 표시한다. 농사 판단에 분 단위 정밀도는 필요하지 않다.

### 공휴일
- 2026·2027년 **우주항공청 월력요항**의 확정 공휴일만 담았다. 대체공휴일을 규칙으로 추정하지 않는다.
- 2026년: 신정, 설날 연휴(2/16~18), 삼일절·대체(3/1~2), 노동절(5/1), 어린이날(5/5), 부처님오신날·대체(5/24~25), 지방선거일(6/3), 현충일(6/6), 제헌절(7/17), 광복절·대체(8/15·17), 추석 연휴(9/24~26), 개천절·대체(10/3·5), 한글날(10/9), 기독탄신일(12/25).
- 2027년: 신정, 설날 연휴·대체(2/6~9), 삼일절(3/1), 노동절·대체(5/1·3), 어린이날(5/5), 부처님오신날(5/13), 현충일(6/6), 제헌절·대체(7/17·19), 광복절·대체(8/15~16), 추석(9/14~16), 개천절·대체(10/3~4), 한글날·대체(10/9·11), 기독탄신일·대체(12/25·27).
- 노동절·제헌절은 2026년 4월 공휴일 지정 법령 개정 이후 월력요항에 반영된 값이다.
- **임시공휴일과 선거일은 발표 시점에 따라 추가된다.** 2027년 이후 선거일은 해당 연도에 확정되므로 이 파일에 미리 넣지 않는다.

### 농사 문안
- 24절기별 일반 영농 안내 3개씩. 지역·품종·기상에 따라 다르므로 단정하지 않는다.
- 앱은 상세 패널에 "참고"와 면책 문구를 고정 표시한다.
- **구현 전 사용자(농사 경험) 또는 지역 농업기술센터 검수가 필요하다.** 검수 전에는 초안으로 본다.

## 4. 생성·검증

```bash
python3 -m venv .venv-calendar
.venv-calendar/bin/pip install korean-lunar-calendar ephem
.venv-calendar/bin/python scripts/gen-calendar-data.py
```

자산이 원본과 같은지 확인만 하려면:

```bash
.venv-calendar/bin/python scripts/gen-calendar-data.py --check
```

Gradle 테스트는 자산을 직접 읽어 다음을 검증한다.

```bash
./gradlew test --tests 'com.borasarang.daon.data.calendar.*'
```

- 음력 5,844일 누락 없음, 날짜 연속성, 음력 일·월·윤달 전이
- 알려진 설날·추석·기준일
- 24절기 16년 × 24개, 연도별 순서·날짜 증가
- 2026년 24절기 KASI 값 전체 일치
- 절기 설명 ko/en 24개, 한자·이름·농사일 개수 일치
- 공휴일 46일, 2026~2027 범위, 필수 필드, 대체공휴일 근거

## 5. 갱신 절차 (T-023)

1. 새 연도 월력요항이 발표되면 `scripts/calendar-src/holidays_2026_2027.json`에 확정 공휴일을 추가한다.
   - 파일 이름과 `range`도 새 범위에 맞춘다(예: `holidays_2027_2028.json`).
   - 임시공휴일·선거일은 관보 확정 후에만 넣는다.
2. 음력·절기 범위를 늘리려면 `scripts/gen-calendar-data.py`의 `END_YEAR`를 조정한다.
3. `python scripts/gen-calendar-data.py`로 자산을 다시 만들고 `./gradlew test`를 통과시킨다.
4. `docs/api/CALENDAR_DATA.md`의 기준일·출처·검증 결과를 갱신한다.
5. 앱 설정 하단의 "공휴일 데이터: 2026–2027" 표시도 함께 바꾼다.

## 6. 알려진 한계

- 2026년 외 절기 시각은 계산값이며 공식 표와 ±1분 차이가 날 수 있다.
- 2027년 이후 임시공휴일·선거일은 포함되지 않는다.
- 음력·절기 범위(2025–2040)를 벗어나면 앱은 음력·절기를 숨기고 안내해야 한다(틀린 값을 표시하지 않는다).
- 농사 문안은 일반 안내이며, 농약 희석·살포량 같은 위험 정보는 넣지 않는다.
