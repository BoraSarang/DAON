# DAON v0.2 목업 — 농사 달력 키오스크

> 상태: **제안·목업 완료, 구현 전 승인 대기** (2026-10-31)
> 대상: 70대 어르신 / Fire HD 10 1920×1200 가로 / 다크 테마
> 목적: v0.1(시계·달력·날씨 3분할)을 **달력 중심 농사 달력 + 3화면 로테이션**으로 재설계

## 1. 보는 방법

가장 간단한 방법은 `index.html`을 브라우저로 여는 것입니다.

```bash
open docs/mockups/v0.2/index.html
```

로컬 서버로 열려면:

```bash
cd docs/mockups/v0.2
python3 -m http.server 8787
# http://localhost:8787/index.html
```

상단 툴바에서 화면을 바꿀 수 있습니다. 목업에서는 자동 전환이 **12초**로 빠르게 동작합니다(실제 제안 기본값은 달력 30초 / 날씨 20초 / 시계 20초).

### 상호작용

| 동작 | 결과 |
|---|---|
| 상단 `달력 (메인)` | 달력 홈 |
| 상단 `날씨` / `시계` | 날씨 메인 / 시계 메인 |
| 상단 `설정` | 인앱 우측 설정 패널 |
| 상단 `절기 설명` | 상강 상세 패널 |
| 달력의 **10/8(한로), 10/23(상강)** 클릭 | 24절기 설명 + 농사일 |
| 달력의 **10/3, 10/5, 10/9** 클릭 | 공휴일 설명 |
| 아무 날짜 클릭 | 음력·절기·공휴일 상세(없으면 날짜 정보) |
| 날씨/시계 화면 아무 곳 클릭 | 달력으로 복귀 (자동 전환 리셋) |
| 설정 → 시계 모양 | 둥근 아날로그 / 큰 디지털 / 혼합 선택 |

### 캡처용 URL

```text
index.html?capture=1&screen=calendar
index.html?capture=1&screen=weather
index.html?capture=1&screen=clock&face=analog|digital|hybrid
index.html?capture=1&screen=settings
index.html?capture=1&screen=term&date=2026-10-23
```

## 3. 데이터 기준

- **날짜·음력·24절기·공휴일은 실제 2026년 데이터**로 맞췄습니다.
  - 2026-10-31 = 음력 9월 21일
  - 2026년 10월 절기: 한로 10/8, 상강 10/23
  - 2026년 10월 공휴일: 개천절 10/3, 대체공휴일 10/5, 한글날 10/9
- **날씨 수치는 예시 데이터**입니다. 실제 구현은 Open-Meteo 현재/시간별/7일 예보를 사용합니다.
- 절기 설명·농사일은 일반적인 영농 정보를 바탕으로 작성한 **목업 문안**입니다. 구현 전에 지역 농협·농업기술센터 자료로 검수해야 합니다.

## 4. 이 목업이 정한 것 / 아직 정하지 않은 것

정한 것:
- 달력 70% / 오른쪽 30% (시계+날씨)
- 3화면 로테이션, 터치 시 달력 복귀
- 달력 셀에 양력·음력·공휴일·절기 동시 표시
- 날짜 클릭 → 우측 상세 패널(다이얼로그 아님)
- 70대 기준 큰 글씨·큰 터치 영역·높은 대비
- 시계 3종(아날로그/디지털/혼합)

정하지 않은 것(승인 필요):
- 기본 글씨 크기(크게 vs 아주 크게)
- 기본 시계 모양(아날로그 추천)
- 자동 전환 간격(30/20/20초 추천)
- 라이트 테마 추가 여부
- 공휴일 데이터 갱신 방식(앱 업데이트 vs 네트워크)
- 농사 문안 검수 주체·일정

상세 계획은 `docs/plans/PLAN_v0.2_android.md`를 참고하세요.
