## 1. 목표 (1줄)
70대 어르신이 벽에 걸어 두고 보는 **농사 달력**을 중심으로, 음력·한국 공휴일·24절기와 농사일을 한눈에 읽고, 손대지 않으면 날씨·시계 화면으로 조용히 넘어가는 키오스크로 재설계한다.

## 2. 왜 바꾸는가 (v0.1 → v0.2)
v0.1은 시계 34% / 달력 40% / 날씨 26%의 3분할이었다. 하지만 실제 주 사용자는 70대 어르신이고, 이 앱의 목적은 **농사 달력**이다. 따라서:

| 항목 | v0.1 | v0.2 제안 |
|---|---|---|
| 주인공 | 시계와 달력이 비슷한 비중 | **달력 70%** |
| 오른쪽 30% | 달력 일부 + 날씨 | **시계 + 날씨 요약** |
| 달력 정보 | 양력·요일 | 양력 + **음력 + 공휴일 + 24절기** |
| 절기 | 없음 | 셀 표시 + **클릭 설명 + 농사일** |
| 화면 | 1개 고정 | **달력 → 날씨 → 시계 3화면 자동 전환** |
| 터치 | 설정 패널 | **아무 곳이나 터치 → 달력 복귀** |
| 날씨 | 현재 + 3일 | 현재 + **시간별 + 7일 + 농사 참고 + 날씨 효과** |
| 시계 | 1종 | **아날로그 / 디지털 / 혼합 선택** |
| 글씨 | 18sp 본문 | **70대 기준 24~30sp 본문, 47sp 날짜** |

## 3. 전제 체인 (깨지는 지점)
1. **대상 기기**: Fire HD 10 2019 / Fire OS 7.3.1.2 / API 28 / 1920×1200 가로 / 240dpi.
   - GMS 없음 → 위치 자동 감지·Firebase·Play 결제 금지. 도시 수동 선택 유지.
   - API 28 → dynamic color, predictive back, SplashScreen API 사용 금지.
2. **상시 표시**: 화면 꺼짐 방지 + 몰입형. 1시간 연속 실행 시 메모리 증가 ≤10MB (T-006).
3. **농사 정보의 정확성**: 음력·24절기·공휴일은 공식 데이터(KASI) 기준. 농사일 문안은 지역·품종·연도에 따라 달라지므로 **단정하지 않고 안내 + 면책**을 함께 표시한다.
4. **공휴일은 해마다 바뀐다**: 대체공휴일·임시공휴일은 규칙만으로 확정할 수 없다. 공식 월력요항을 번들하고 **연 1회 갱신**을 전제로 한다.
5. **70대 사용자**: 작은 글씨·복잡한 조작·빠른 애니메이션을 이해하지 못할 수 있다. 기본값은 크게, 조작은 "누르면 돌아온다" 하나로 단순화한다.
6. **라디오는 후속**: v0.2에 넣지 않는다. 화면 목록을 확장 가능한 구조로 두고 v0.3에서 추가한다.

## 4. 범위

### 포함 (v0.2)
1. **달력 홈 (70%)**: 6×7 그리드, 양력·음력·공휴일·24절기, 오늘 강조, 월 이동, 오늘 버튼.
2. **오른쪽 30%**: 큰 시계 + 날씨 요약(현재/최고·최저/강수/습도/바람/3일).
3. **농사 달력**: 오늘의 절기 + 농사일 스트립, 날짜 상세 패널(절기 설명·농사일·공휴일 설명).
4. **3화면 로테이션**: 달력(30초) → 날씨(20초) → 시계(20초). 설정에서 켜기/끄기, 화면별 시간(10/20/30/60초), 터치 동작(`대시보드로 복귀` 기본 / `그 화면에서 멈추기`) 변경.
5. **날씨 메인**: 현재/체감/강수확률/강수량/습도/바람, 시간별(3시간 간격 8칸), 이번 주 7일, 농사 참고 배너, 비·눈·천둥·맑음 애니메이션.
6. **시계 메인**: 둥근 아날로그(기본), 큰 디지털, 아날로그+디지털. 설정에서 선택·즉시 반영.
7. **설정**: 자동 전환(화면별 시간·터치 동작), 시계 모양, 글씨 크기(보통/크게/아주 크게), 날씨 단위, 시간 표시, 언어, 도시, 날씨 움직임 켜기/끄기.
8. **i18n**: en(기본) + ko. 새 문자열·절기·공휴일·농사 문안 모두 `values/strings.xml` / `values-ko/strings.xml` + assets.
9. **접근성**: 큰 터치 영역(≥64dp), 색+텍스트 이중 표시, 고대비, 모션 줄이기.
10. **데이터 자산**: 음력 2025–2040, 24절기 2025–2040, 공휴일 2026–2027(공식), 절기·농사 문안 24개.

## 5. 화면 설계

### 공통
- 1920×1200, 외곽 40px, 패널 간격 24px, 다크 테마(`docs/DESIGN.md` v0.2 토큰).
- 상단 바 88px: 오늘 날짜(48px) + 음력·절기(27px), 오른쪽 화면 점 3개 + 설정(64px).
- 화면 전환은 250ms 크로스페이드. 급격한 슬라이드·확대 금지(어르신 방향 감각).
- 화면 표시 점은 장식이며 터치 대상이 아니다. 터치 동작은 설정에 따라 `대시보드로 복귀`(기본) 또는 `그 화면에서 멈추기` 하나로 단순하게 유지한다.

- 달력 폭 70% (≈1268px), 오른쪽 30% (≈543px).
- 달력 셀: 양력 47px/700, 음력 25px/500, 공휴일·절기 21px/700. 오늘은 amber 배경 + "오늘" 라벨.
- 공휴일은 빨강 + 이름, 절기는 초록 + 이름, 일요일 빨강, 토요일 파랑. 색만으로 구분하지 않는다.
- 오른쪽: 시계 카드 320px + 날씨 카드 나머지. 날씨 카드 하단에 3일 미니 예보 + 농사 참고.
- 하단 농사 스트립 98px: 현재 절기 + 오늘 할 일 1줄.

### 5.2 날짜 상세 패널 (`screens/05-term.png`)
- 오른쪽 820px 인앱 패널 + scrim. **다이얼로그 창을 쓰지 않는다**(키오스크 시스템 바 재등장 방지).
- 절기: 이름·한자·날짜·음력·설명·농사일 3~4개·이달의 절기 칩·이달의 공휴일·면책.
- 공휴일: 이름·날짜·설명·이달의 공휴일. 공휴일이 아닌 날: 음력·요일 안내.
- 패널이 열리면 자동 전환 일시정지. 닫으면 달력 복귀.

### 5.3 날씨 메인 (`screens/02-weather.png`)
- 상단: "오늘 날씨" + 도시·갱신 시각 + 터치 안내.
- 히어로 540px: 현재 기온 196px, 상태, 체감, 강수확률·강수량·습도·바람, "오늘은 우산이 필요합니다" 요약.
- 오른쪽: 이번 주 7일(최고/최저, 강수확률).
- 농사 참고 배너: 비 ≥60% → "농약 살포 자제", 최저 ≤0° → "서리 주의", 최고 ≥33° → "한낮 작업 피하기", 바람 ≥9m/s → "비닐하우스 점검". 단정 대신 "참고" 문구 + 면책.
- 하단 시간별 8칸(3시간 간격): 시각·아이콘·기온·강수량 막대.
- 배경 효과: 비(빗줄기), 눈, 천둥(번개 플래시), 맑음(느린 구름/햇빛). Canvas 파티클 40~60개, 60fps, 화면 밖/설정 끄기 시 정지.
- 오프라인: 마지막 성공값 + "오프라인" 배지. 시계·달력은 계속 동작.

### 5.4 시계 메인 (`screens/03-clock.png`, `06`, `07`)
- 날짜(42px) + 시계 얼굴 + 음력·절기 + 현재 날씨.
- **둥근 아날로그(기본)**: 지름 720px, 숫자 60~74px, 시침 22px·분침 13px·초침 5px(amber). 12/3/6/9 강조.
- **큰 디지털**: 오후/오전 58px + 3:24 300px + 초 44px.
- **혼합**: 아날로그 560px + 디지털 118px.
- 하단에 터치 안내: `대시보드로 복귀` 모드 `아무 곳이나 누르면 달력으로 돌아갑니다` / `그 화면에서 멈추기` 모드 `아무 곳이나 누르면 자동 전환을 멈춥니다`.

### 5.5 설정 (`screens/04-settings.png`)
- 인앱 우측 760px 패널. 항목:
  1. 화면 자동 전환 (켜기/끄기) + 화면별 유지 시간(달력/날씨/시계 × 10/20/30/60초) + 터치 동작(`대시보드로 복귀` / `그 화면에서 멈추기`)
  2. 시계 모양 (3개 카드, 즉시 미리보기)
  3. 글씨 크기 (보통/크게/아주 크게, 기본 크게)
  4. 날씨 단위 °C/°F
  5. 시간 표시 오전·오후/24시간
  6. 언어 한국어/English
  7. 도시 선택
  8. 날씨 움직임 켜기/끄기
- 설정은 즉시 적용 + SharedPreferences 저장. 재시작 후 유지.
- 자동 전환 기본: 달력 30초 / 날씨 20초 / 시계 20초. 화면별로 따로 변경할 수 있다.
- 터치 기본값은 `대시보드로 복귀`: 날씨·시계 화면을 누르면 달력으로 돌아가고 타이머가 리셋된다.
- `그 화면에서 멈추기` 선택 시: 날씨·시계 화면을 누르면 그 화면에 그대로 멈추고, 다시 누르면 자동 전환이 재개된다.
- 설정·상세 패널이 열려 있으면 자동 전환을 멈춘다.

## 6. 데이터 전략

### 6.1 음력 (2025–2040)
- 한국천문연구원(KASI) 음력 데이터를 기반으로 **연도별 음력 월 길이·윤달 테이블**을 생성해 `app/src/main/assets/calendar/lunar_2025_2040.json`으로 번들.
- 런타임 라이브러리 의존성 없이 계산. 생성 스크립트 `scripts/gen-calendar-data.py`.
- 검증: 2026-10-31 = 음력 9/21, 2026-09-25 = 8/15(추석), 2026-02-17 = 1/1(설날) 등 알려진 날짜 단위 테스트.
- 범위 밖 날짜: 음력 숨김 + "음력 데이터 없음" 안내(조용히 틀린 값 표시 금지).

### 6.2 24절기 (2025–2040)
- 태양 황경 기반 천문 계산으로 KST 절입 시각을 생성해 `solar_terms_2025_2040.json`으로 번들. 2026년은 KASI 발표값과 대조(한로 10/8 15:29, 상강 10/23 18:37 등).
- 셀에는 날짜의 절기 이름, 상세 패널에는 절입 시각까지 표시.
- 절기 문안·농사일: `assets/calendar/terms_ko.json`, `terms_en.json`. 24절기 × 설명 1 + 농사일 3~4.

### 6.3 공휴일 (2026–2027)
- KASI 월력요항의 **확정 공휴일**을 `holidays_2026_2027.json`으로 번들. 대체공휴일·임시공휴일은 규칙으로 계산하지 않고 공식 값만 사용.
- 각 항목: 날짜, 이름, 종류(국경일/명절/대체/임시), 설명(ko/en).
- 설정 하단에 "공휴일 데이터: 2026–2027" 표시. 범위 밖 연도는 공휴일 표시를 끄고 안내.
- **연 1회 갱신 작업**을 TODO에 등록(T-023). 갱신 방법은 승인 필요(앱 업데이트 vs 네트워크 API).

### 6.4 농사일 문안
- 절기별 일반 영농 안내(예: 상강 — 김장 배추·무 수확, 보리 파종 마무리, 서리 대비).
- 지역·품종·기상에 따라 다르므로 **"참고" + 면책**을 고정 표시. 농약 희석·살포량 같은 위험 정보는 넣지 않는다.
- 구현 전에 사용자(농사 경험) 또는 지역 농업기술센터 자료로 1회 검수한다.

### 6.5 데이터 파일·라이선스
- `docs/api/CALENDAR_DATA.md`에 출처·기준일·생성 명령·검증 결과를 기록.
- KASI 공공데이터 출처 표기. 생성 스크립트와 원본 테이블은 저장소에 함께 둔다.

## 7. 70대 접근성 기준
- **글씨**: 기본 본문 27~30px, 보조 21~25px, 핵심 숫자 47px 이상. 18px 이하 금지.
- **굵기**: W300 금지. 본문 W500, 라벨 W700.
- **대비**: primary `#F5F7FA` on `#0B0D10` ≈ 17:1, secondary `#C3CBD6` ≈ 10:1, muted `#8E98A6` ≈ 6:1.
- **터치**: 최소 64px, 날짜 셀 180×115px, 설정 행 72px.
- **색+텍스트**: 공휴일은 빨강 + 이름, 절기는 초록 + 이름, 오늘은 amber + "오늘" 라벨.
- **모션**: 날씨 효과 끄기 설정. 화면 전환 250ms. 깜빡임 최소.
- **조작**: "아무 곳이나 누르면 달력" 하나. 스와이프·롱프레스·더블탭 없음.
- **글씨 크기 3단계**: 보통/크게/아주 크게. 1.25배에서도 1920×1200 레이아웃이 깨지지 않는지 검증.
- **사용자 테스트**: 70대 사용자가 도움 없이 ① 오늘 음력 찾기 ② 상강 설명 열기 ③ 시계 모양 바꾸기 3가지를 완료하는지 확인.

## 9. 성능·검증 예산
- Cold start ≤2.0s (v0.1 1.54s에서 자산 로드 증가분 <100ms)
- PSS ≤250MB (v0.1 65.5MB)
- 60fps 상시 렌더링, 날씨 애니메이션 60fps
- 1시간 연속 실행 메모리 증가 ≤10MB (T-006)
- 날씨 갱신 15분 + 수동, 캐시 마지막 성공값
- 데이터 자산 <300KB, 시작 시 1회 로드
- 애니메이션 정지: 화면 비활성·설정 끄기·저전력? (저전력은 후속)
- 단위 테스트: 음력·절기·공휴일·로테이터(화면별 시간·터치 2모드)·WMO 매핑
- i18n 키 패리티 100%
- 실기기: Fire HD 10 `G0012C0594231E2V`, 1시간 상시, 화면 꺼짐/재개
