# PLAN v0.4 — TV (DAON)

> 작성: 2026-11-01 | 플랫폼: android (Fire HD 10, API 28)
> 참고: `/Users/lee/Documents/Apps/BoraSarang/AnywhereTV` (실측 스트림·리졸버)
> 이전: v0.3 라디오 (`docs/plans/PLAN_v0.3_radio.md`)

## 1. 목표
키오스크 대시보드에 **TV 화면**을 더한다. 채널 목록에서 하나를 누르면 바로 재생되고,
`전체 화면`으로 영상만 크게 볼 수 있다. **TV가 나오는 동안(전체 화면 포함)에는 화면 자동 전환이 멈춘다.**
라디오와 TV는 동시에 나오지 않는다.

## 2. 채널 (6개, 방송사 공식 무료 스트림만)
| 채널 | 방식 | 주소 |
|---|---|---|
| KBS 1TV | JSON `channel_item[0].service_url` | `cfpwwwapi.kbs.co.kr/.../channel_code/11` |
| KBS 2TV | 동일 | `.../channel_code/12` |
| MBC | JSON `MediaInfo.MediaURL` | `mediaapi.imbc.com/Player/OnAirURLUtil?type=PC&onairtype=5` |
| SBS | JSON `onair.source.mediasource.mediaurl` | `apis.sbs.co.kr/play-api/1.0/onair/channel/S01?...&ssl=Y` |
| EBS 1TV | 직접 m3u8 | `ebsonair.ebs.co.kr/ebs1familypc/familypc1m/playlist.m3u8` |
| EBS 2TV | 직접 m3u8 | `ebsonair.ebs.co.kr/ebs2familypc/familypc1m/playlist.m3u8` |

- 유튜브 뉴스 채널은 넣지 않는다(공식 스트림 아님, 광고·자동재생 정책 불안정).
- MBC CDN 은 `Referer: https://onair.imbc.com/` 없이는 **403** 을 준다. 확인할 때와 재생할 때 모두 같은 헤더를 붙인다.
- SBS 는 주소를 `http://` 로 줄 때가 있다. 기기가 평문 HTTP 를 막으므로 `https://` 로 올린다.
- 목록은 `assets/tv_channels.json` 에 분리한다. 스트림 주소는 매 재생마다 새로 확인한다(토큰 만료).

## 3. 화면 설계 (1920×1200)
- **5번째 화면 `TV`**: 달력 → 라디오 → **TV** → 날씨 → 시계. 화면 점 5개.
- **왼쪽(약 66%)**: 16:9 영상 판(검은 배경, 16:9를 넘으면 위아래 검게) + 아래 조작 줄.
  - 조작 줄: `지금 방송`/`마지막 채널` + `LIVE`, 채널 이름 30sp, `보는 중 · 00:00:12`,
    84dp 원형 `재생/멈춤`, `전체 화면` 버튼(재생 중에만 켜짐).
- **오른쪽(약 34%)**: `채널` 제목 + 6칸(2×3). 이름 23sp + 분류(지상파/교육).
  보는 중인 칸은 accent 테두리 + `보는 중` + 이퀄라이저.
- **전체 화면**: 영상만 화면에 꽉 채우고(레터박스), 오른쪽 위에 채널 이름 + `전체 화면 나가기`.
- **안내 한 줄**: `TV를 보는 동안에는 화면이 자동으로 넘어가지 않습니다.`
- 오류: 조작 줄에 `채널을 불러오지 못했습니다` + `다시 시도` 칩. danger 색은 문구에만.

## 4. 화면 이동·자동 전환 (핵심)
- **자동 전환 정지 조건**: `설정 열림 || 날짜 상세 열림 || TV 재생/연결 중 || 전체 화면`.
  재생을 멈추면 그 화면에 머무는 시간이 다시 시작되고, 시간이 지나면 다음 화면으로 넘어간다.
- **TV 화면을 떠나면 정지**: `달력` 버튼, 뒤로가기, 앱이 내려갈 때(ON_STOP) 모두 `stopTv()`.
- **빈 곳 터치 무시**: 라디오와 같다. 터치는 채널·재생·전체 화면에만 쓴다.
- **라디오 ↔ TV**: 하나를 시작하면 다른 하나를 먼저 멈춘다. 소리가 겹치지 않는다.
- **뒤로가기**: 전체 화면이면 먼저 전체 화면을 나가고, 그다음이 달력.

## 5. 설정 (설정 → TV)
- `TV 화면 포함` (기본 켜짐) — 끄면 4화면 로테이션.
- `TV 화면 시간` 10/30/60초 (기본 30초). 재생 중에는 시간이 흘러도 넘어가지 않는다.
- `기본 채널` — 앱을 열 때 고를 채널(기본 KBS 1TV).

## 6. 기술 설계
- **재생**: Media3 ExoPlayer 1.5.1 + `media3-ui` `PlayerView`(컨트롤 숨김). 첫 재생 때 플레이어 생성(콜드 스타트 보호).
- **헤더**: `TvStream(url, headers)`. MBC 는 `Referer`/`Origin` 을 `DefaultHttpDataSource` 기본 요청 속성으로 넘긴다.
- **리졸버**: `TvResolver` — KBS/MBC/SBS JSON 파싱, DIRECT 는 자산의 주소. 타임아웃 8/12초, 재시도 1회.
- **오류 코드**: `E-AND-TV-0001`(채널 정보), `E-AND-TV-0002`(주소 확인), `E-AND-TV-0003`(재생).
- **수명**: `DashboardViewModel` 에 플레이어 1개. 앱이 내려가면 정지. 백그라운드 재생 서비스 없음.
- **성능**: 영상 판은 `PlayerView` 1개. 플레이어는 화면에서 처음 재생할 때 만든다.

## 7. 검증 (실기기 Fire HD 10, 2026-11-01)
- 6채널 모두 재생: KBS1(저작권 안내 화면), KBS2, MBC(드라마), SBS(가요), EBS1(다큐), EBS2(컬러바).
- 전체 화면 진입·나가기, 전체 화면에서도 자동 전환 정지(75초 이상 유지).
- 재생 중 15초 dwell 을 넘겨도 화면이 넘어가지 않음. 멈추면 다시 넘어감.
- `달력` 버튼·홈 키(ON_STOP)에서 정지. 라디오 재생 중 TV 를 켜면 라디오가 먼저 멈춤(AudioTrack 44.1k → 48k).
- 콜드 스타트 1.945–2.021s(중앙값 1.962s), 예산 2.0s.
