## 1. 목표
키오스크 대시보드에 **라디오 화면**을 더한다. 어르신이 채널을 한 번 누르면 바로 재생되고,
다른 화면(달력·날씨·시계)으로 넘어가도 소리는 계속 나온다. 조작은 `재생/멈춤`, `채널 선택`, `소리` 세 가지로 끝낸다.

## 3. 화면 설계 (1920×1200)
- **4번째 화면 `RADIO`**: 달력 → **라디오** → 날씨 → 시계. 화면 점은 4개.
- **지금 방송 패널** (높이 352px): `지금 방송` + `LIVE`, 채널 이름 96sp, `FM 97.3`, `재생 중 · 00:12:34`.
  오른쪽에 196px 원형 `멈춤/재생` 버튼, 그 옆에 `소리 − / 10칸 / +`.
- **채널 10칸** (5×2): 이름 35sp + `FM 97.3` 25sp. 재생 중인 칸은 accent 테두리 + `재생 중` + 이퀄라이저.
  한 칸 크기 약 352×230px — 70대가 한 번에 누를 수 있는 크기.
- **안내 한 줄**: `다른 화면으로 넘어가도 소리는 계속 나옵니다.`
- 프로그램명(EPG)은 넣지 않는다. 실데이터가 없어서 가짜 편성표를 만들지 않는다.

## 4. 화면 이동 (핵심)
- **라디오 → 달력**: 상단 바의 **`달력` 버튼**. 날씨·시계와 같은 위치·같은 모양(accentSoft).
  - 드래그·스와이프는 쓰지 않는다. 70대에게 발견하기 어렵고, 채널 칸 터치와 충돌한다.
  - 라디오 화면은 **빈 곳을 눌러도 달력으로 가지 않는다**. 터치는 채널 선택·재생에만 쓴다.
  - `그 화면에서 멈추기` 모드에서도 이 버튼으로 항상 돌아올 수 있다.
- **달력 → 라디오**: 상단 바의 `♪ KBS 1라디오` 표시(재생 중일 때만)를 누르면 라디오 화면으로 간다.
  재생 중이 아니면 표시가 없고, 자동 전환으로 라디오 화면이 오면 된다.
- **자동 전환**: 라디오 화면 30초(10/30/60초 설정). 달력으로 돌아가도 **소리는 유지**한다.
- **멈춤**: 라디오 화면의 큰 버튼. 달력에서 멈추려면 상단 표시 → 라디오 화면 → 멈춤.

## 6. 기술 설계
- **재생**: Media3 ExoPlayer + `media3-exoplayer-hls`. GMS 불필요(Fire OS OK). AAC/HLS 재생.
- **리졸버**: PADO `ResolverService` 를 Kotlin 으로 이식.
  - KBS: `GET cfpwwwapi.kbs.co.kr/.../channel_code/{21|22|25}` → `channel_item[0].service_url`
  - MBC/SBS: 응답 본문이 m3u8 URL plain text (MBC는 `User-Agent` 필요)
  - direct: 고정 m3u8
  - 매 재생마다 resolve (CloudFront/JWT/`_lsu_sa_` 만료 대응), 타임아웃 12초, 재시도 1회
- **오디오**: `AudioManager` STREAM_MUSIC, 오디오 포커스 획득/상실 처리. 전화·다른 앱이 오면 일시정지.
- **수명**: `DashboardViewModel`(또는 `App` 스코프)에 플레이어 1개. 화면 전환과 무관하게 유지.
  앱이 백그라운드로 가면 정지. (v0.3은 포그라운드 서비스 없이. 상시 키오스크라 화면이 꺼지지 않는다.)
- **상태**: `RadioUiState(channel, playing, buffering, error, volume)`. 재생 중 채널 id는 `AppPrefs`에 저장.
- **오류**: `E-AND-RADIO-0001`(채널 정보 없음), `0002`(네트워크/리졸버 실패), `0003`(스트림 재생 실패).
  화면에는 `방송을 불러오지 못했습니다` + `다시 시도` 버튼. 무음 실패 금지.
- **성능**: 재생 중에도 콜드 스타트 예산 2000ms 유지(플레이어는 화면 진입 시 lazy 생성). PSS +20MB 이내 목표.

## 7. 개인정보·데이터
- 방송 청취는 방송사 서버와의 HTTPS 통신만 한다. 계정·로그인·광고 없음.
- 채널 선택·재생 상태는 기기 SharedPreferences에만 저장. 외부 전송 없음.
- `data_safety.md` 에 "라디오 청취를 위해 방송사 스트림에 접속" 항목 추가. 새 권한은 없다(INTERNET 기존).
