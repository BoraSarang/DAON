# PLAN v0.11 — 뉴스 전용 화면 + 화면 터치 3가지 (DAON)

> 작성: 2026-11-02 | 플랫폼: android (Fire HD 10, API 28) | 성격: 기능 추가(M)
> 목업: `docs/mockups/v0.11-news/index.html` (승인)

## 요구
1. 자동 전환에 **뉴스 화면**을 넣는다. 요약이 아니라 **기사 전문**을 큰 글씨로 보여 준다.
2. 본문이 길면 **위아래 스크롤**해서 읽는다. 읽는 동안 화면이 넘어가지 않게 한다.
3. 뉴스 화면에서 **멈춘 상태**면 좌우로 밀어 이전·다음 기사를 본다.
4. 달력 상단의 **뉴스 티커 → 오른쪽 패널** 기능은 그대로 둔다.
5. 화면을 한 번 눌렀을 때의 동작을 사용자가 고른다(대시보드 복귀/멈추기/고정). **두 번 누르면 달력**.
6. 라디오·TV는 지금처럼 `사용 안 함`으로 자동 전환에서 뺄 수 있고, 두 번 탭 예외도 유지한다.

## 결정
- 터치 동작은 `TouchAction` 3가지: `DASHBOARD`(기본), `PAUSE_TOGGLE`, `FIXED`.
  기존 `touch_stop=true` 는 `PAUSE_TOGGLE` 로 읽어 마이그레이션한다.
- 자동 전환 순서: **달력 → 뉴스 → 라디오 → TV → 날씨 → 시계**.
  뉴스는 뉴스 티커가 켜져 있을 때만 순서에 들어간다(기사가 없으면 보여 줄 것이 없음).
- 뉴스 화면 머무는 시간: 10/30/60초(기본 30초). 기사는 그 안에서 **10초마다** 다음으로 넘어간다.
  그래서 30초면 기사 3건을 본다.
- 본문을 스크롤하면 그 화면에서 자동 전환이 **멈춘다**. 하단에 `멈춤` 배지,
  `← → 좌우로 밀어 이전·다음 기사`, `▶ 자동 넘김 다시 시작` 을 보여 준다.
- 좌우 밀기는 **멈춘 상태에서만** 동작한다. 자동 전환 중 오작동을 막는다.
- 라디오·TV는 두 번 탭해도 달력으로 가지 않는다(채널·재생 조작 우선).
- 기사 본문은 기사 주소로 메모리에 기억해, 화면이 다시 돌아와도 재요청하지 않는다.

## 구현
- `core/TouchAction.kt`: 3가지 열거형.
- `core/AppPrefs.kt`: `touch_action`, `news_in_rotation`, `dwell_news` 키 + `touch_stop` 마이그레이션.
- `ui/ScreenMode.kt`: `NEWS` 추가, `next()`·`order()` 에 `includeNews`.
- `ui/ScreenChrome.kt`: 점·헤더에 `includeNews`, `rotationHintRes(action, stopped)`.
- `ui/NewsScreen.kt`: 제목 40sp·본문 24sp/38sp, 스크롤, 하단 페이드, 10초 진행 막대,
  멈춤 배지·좌우 밀기·다시 시작 버튼.
- `ui/DashboardScreen.kt`: 3-way 탭 + 더블 탭, 뉴스 기사 인덱스·10초 타이머, 기사 로딩.
- `ui/DashboardViewModel.kt`: 터치/뉴스 설정 상태, `loadNewsFeedArticle` + 본문 캐시.
- `ui/SettingsPanel.kt`: 터치 3칩, 뉴스 화면 토글·머무는 시간.
- `values`/`values-ko`: 새 문구 18개(패리티 검사).
